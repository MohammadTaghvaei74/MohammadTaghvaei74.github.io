# Mohammad Taghvaei - personal portfolio

A responsive portfolio for a crypto product leader and trading systems architect. Built with plain HTML, CSS, and JavaScript for GitHub Pages; no build step or package installation is required.

## Preview locally

Run `python -m http.server 8000` from this directory, then visit `http://localhost:8000`.

## Update the site

- `index.html`: portfolio content, product links, contact information, and social metadata.
- `styles.css`: design tokens, layouts, responsive styles, and reduced-motion support.
- `script.js`: mobile navigation, product filters, email copying, and scroll reveals.
- `1720347391844.jpg`: original portrait.
- `assets/favicon.svg`: site icon.

Core content, navigation, and contact links work without JavaScript. Google Fonts provides DM Sans and Space Grotesk with local fallback fonts. The product visual is an illustration, not a trading interface or market performance chart.

Experience and platform figures are carried over from the original portfolio; exchange-wide scale is explicitly separate from personal product delivery. Review these figures as the portfolio evolves.

## Publish

Push the site files to the branch configured in the repository's **Settings > Pages**. This site works directly from the repository root. No backend or API keys are needed.
